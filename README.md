# ts-spacex-api-demo
SPA en React + TS para comparar el rendimiento entre REST (Swagger) y GraphQL consumiendo la API de SpaceX. Incluye métricas de latencia y tamaño de payload probadas con k6. | React + TS SPA comparing REST (Swagger) vs. GraphQL performance using the SpaceX API. Features latency and payload size metrics benchmarked with k6.
